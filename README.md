## 📋 Описание

Реляционная база данных для управления автозаправочной станцией. Хранит информацию о станциях, пользователях, продажах топлива и ценах.

## 🗄️ Структура базы данных

### Таблицы

#### `AZC` — Автозаправочные станции
- `ID_АЗС` — уникальный идентификатор станции
- `Название_Станции` — название АЗС
- `Адрес_Расположения` — адрес
- `Количество_Колонок` — количество топливных колонок
- `Режим_Работы` — график работы

#### `Пользователи` — Пользователи системы
- `ID_Пользователя` — уникальный идентификатор
- `Фамилия`, `Имя` — ФИО
- `Телефон` — контактный номер
- `Email` — электронная почта
- `Пароль` — пароль для авторизации
- `Роль` — внешний ключ на таблицу `Roles` (Продавец / Администратор / Покупатель)
- `Дата_Регистрации` — дата создания аккаунта

#### `Продажи` — История продаж топлива
- `ID_Продажи` — уникальный идентификатор продажи
- `Дата_Время` — дата и время операции
- `ID_АЗС` — внешний ключ на таблицу `AZC`
- `ID_Продавца` — внешний ключ на таблицу `Пользователи`
- `ID_Покупателя` — внешний ключ на таблицу `Пользователи`
- `ID_Топлива` — внешний ключ на таблицу `Топливо_и_Цены`
- `Объем_Литров` — количество проданного топлива
- `Сумма_Руб` — сумма покупки
- `Способ_Оплаты` — внешний ключ на таблицу `PaymentMethods` (Карта / Наличные)

#### `Топливо_и_Цены` — Каталог топлива
- `ID_Топлива` — уникальный идентификатор
- `Марка_Бензина` — название топлива (АИ-92, АИ-95, ДТ и т.д.)
- `Класс_Экологичности` — внешний ключ на таблицу `EcoClasses` (Евро-5 / Евро-6 / ГОСТ-52041)
- `Цена_За_Литр` — стоимость
- `Остаток_В_Резервуаре_Л` — текущий остаток

### Справочные таблицы

#### `Roles` — Роли пользователей
| RoleID | RoleName |
|--------|----------|
| 1 | Продавец |
| 2 | Администратор |
| 3 | Покупатель |

#### `PaymentMethods` — Способы оплаты
| PaymentID | PaymentName |
|-----------|-------------|
| 1 | Карта |
| 2 | Наличные |
